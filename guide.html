دليل تشغيل شاشة اليوم الوطني ٩٦ التفاعلية

ما الذي في هذا المجلد؟

index.htmlصفحة الطالب: الاسم والشعور والعبارة والصورة (اختيارية).
screen.htmlشاشة العرض: البطاقات تظهر لحظيًا مع رمز QR للمشاركة.
admin.htmlصفحة المشرف: اعتماد البطاقات أو رفضها قبل ظهورها.
config.jsالإعدادات: مفاتيح Supabase واسم الكلية ومدد العرض.
setup.sqlيجهّز قاعدة البيانات والصلاحيات ومجلد الصور.

لمعاينة التصميم قبل أي إعداد: افتح screen.html كما هي، وستعمل بوضع تجريبي ببطاقات وهمية.

الخطوة ١: إنشاء مشروع Supabase مجاني

  1. ادخل إلى supabase.com وأنشئ حسابًا، ثم اضغط New project.
  2. اختر اسمًا للمشروع ومنطقة قريبة، واحفظ كلمة مرور قاعدة البيانات في مكان آمن.
  3. انتظر دقيقة أو دقيقتين حتى يجهز المشروع.

الخطوة ٢: تشغيل ملف الإعداد

  1. افتح setup.sql بأي محرر نصوص.
  2. غيّر ADMIN_EMAIL@example.com إلى البريد الذي سيدخل به المشرف.
  3. في Supabase افتح SQL Editor ← New query، والصق المحتوى كاملًا، واضغط Run.

الخطوة ٣: حساب المشرف

  1. من Authentication ← Users اختر Add user، وأدخل البريد نفسه وكلمة مرور قوية، وفعّل تأكيد البريد تلقائيًا إن ظهر الخيار.
  2. أوقف التسجيل الذاتي حتى لا ينشئ أحد حسابًا: في إعدادات المصادقة ابحث عن Allow new users to sign up وأطفئه.

قد تختلف أسماء القوائم في Supabase قليلًا عما ذُكر هنا، فالواجهة تتغير. المهم أن تنشئ مستخدمًا واحدًا وتمنع التسجيل الجديد.

الخطوة ٤: ربط الصفحات بالمشروع

  1. من Project Settings ← API انسخ Project URL والمفتاح العام (اسمه anon أو publishable).
  2. الصقهما في config.js مكان YOUR-PROJECT و YOUR-ANON-PUBLIC-KEY.
  3. عدّل COLLEGE_NAME إن أردت.

لا تضع مفتاح service_role في أي ملف أبدًا. المفتاح العام وحده هو المخصص للصفحات، وحماية البيانات تعتمد على قواعد setup.sql.

الخطوة ٥: رفع الموقع على استضافة مجانية

الخيار الأبسط GitHub Pages:

  1. أنشئ مستودعًا جديدًا على github.com.
  2. اختر Add file ← Upload files وارفع الملفات الخمسة (ما عدا setup.sql إن أردت).
  3. من Settings ← Pages اختر النشر من الفرع main والمجلد الجذر.
  4. بعد دقائق يظهر رابط بالشكل https://USERNAME.github.io/REPO/.

بدائل مشابهة: Cloudflare Pages أو Netlify. لم أتحقق من شروط الاستضافة المجانية الحالية لأي منها، فراجع صفحاتها الرسمية قبل الاعتماد عليها.

الروابط النهائية

  • الطلاب: …/index.html (يظهر رابطها ورمزها تلقائيًا على الشاشة).
  • الشاشة: …/screen.html على جهاز متصل بالشاشة الكبيرة، واضغط F لملء الشاشة.
  • المشرف: …/admin.html من جوال المشرف أو حاسوبه.

قائمة فحص قبل الفعالية

  1. أرسل بطاقة تجريبية من جوالك بصورة وبدون صورة.
  2. ادخل صفحة المشرف واعتمد البطاقة، وتأكد أنها ظهرت على الشاشة خلال ثوانٍ.
  3. احذف البطاقات التجريبية من صفحة المشرف.
  4. افتح شاشة العرض قبل الفعالية بيوم وبساعة، وأوقف نوم الجهاز وحافظة الشاشة.
  5. ادخل لوحة Supabase قبل الفعالية بيوم على الأقل، فالمشاريع المجانية تتوقف تلقائيًا بعد أسبوع من عدم النشاط.
  6. جرّب الشاشة على الشاشة الفعلية وعلى شبكة الكلية، فقد تحجب بعض الشبكات مواقع الخطوط أو الخدمات.

ملاحظات مهمة

  • الصور تُصغَّر في متصفح الطالب قبل الرفع لتوفير مساحة التخزين المجانية.
  • روابط الصور عشوائية، لكنها عامة لمن يعرف الرابط، حتى قبل الاعتماد.
  • الفاصل الزمني بين البطاقات (٣٠ ثانية) محفوظ في جوال الطالب، وهو تخفيف بسيط للإزعاج وليس حماية قوية من التلاعب. الاعتماد اليدوي هو خط الدفاع الأساسي.
  • بعد الفعالية احذف البطاقات والصور من Supabase أو أوقف المشروع، حفاظًا على خصوصية الطلاب.
  • تأكد من موافقة الكلية على تصوير الطلاب ونشر صورهم على الشاشة، ونموذج الطالب يطلب موافقته صراحةً.
  • لم تُجرَّب هذه الملفات على مشروع Supabase حقيقي أثناء إعدادها، فالاختبار الكامل بالخطوات أعلاه ضروري قبل الفعالية.
